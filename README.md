# AI Toolkit

Ready-to-use setups, prompts and skills for **ChatGPT** and **Claude**. Everything is explained in plain language: what it does, when to use it and how to set it up.

## What's inside

| Folder | What you'll find | Works in |
|---|---|---|
| [custom-instructions](custom-instructions) | An interview prompt that writes your Custom Instructions for you, plus setup steps | ChatGPT and Claude |
| [prompts](prompts) | Ready-to-paste prompts for business, startups, workflows and productivity | ChatGPT and Claude |
| [skills](skills) | Ready-to-install skills with install steps | Claude only |

## Where to start

1. **New to ChatGPT or Claude personalization?** Start with [custom-instructions](custom-instructions). It takes about 10 minutes and improves every answer after that.
2. **Need help with a specific task?** Browse [prompts](prompts) and copy one into a new chat.
3. **Using Claude?** Install a [skill](skills) to change how Claude answers in every chat.

## How to copy a prompt

Open any file with a grey prompt box and click the **copy button** in its top-right corner. Paste it into a new chat.
