# Prompts

Ready-to-paste prompts. Each file explains what the prompt does, when to use it and how to use it. All prompts work in **ChatGPT** and **Claude** unless the file says otherwise.

## Business and startups

| Prompt | What it does |
|---|---|
| [Business Idea Validation](business-and-startups/business-idea-validation.md) | Interviews you about an idea and finds the riskiest assumptions and the cheapest way to test them |
| [Investor One-Pager](business-and-startups/investor-one-pager.md) | Collects your startup facts and writes the text for a one-page investor summary |

## Workflows and productivity

| Prompt | What it does |
|---|---|
| [Workflow Discovery Interview](workflows-and-productivity/workflow-discovery.md) | Finds one recurring work task worth automating and fills in a workflow worksheet |

## How to use a prompt

1. Open the prompt file.
2. Click the **copy button** in the top-right corner of the grey prompt box.
3. Paste it into a **new chat** in ChatGPT or Claude and send it.
